# Development and debugging

## Toolchain

Use the exact versions in `rust-toolchain.toml`, `.node-version`, and `package.json`. Commit lockfiles generated by Cargo and pnpm. Install JavaScript dependencies with `pnpm install --frozen-lockfile` on clean checkouts and in CI; use `pnpm add -E` for intentional dependency changes. Review changes to lockfiles as code changes.

Xcode supplies the macOS SDK, Clang, linker, and debugger. CMake is installed in preparation for the later llama.cpp milestone. SQLite will be bundled through rusqlite when storage is implemented. No database server, Docker daemon, Ollama server, or cloud infrastructure is needed.

Homebrew installs rustup outside its default PATH. Add `$(brew --prefix rustup)/bin` to your shell PATH. The Makefile and Tauri launcher also discover standard Homebrew and rustup toolchain locations.

## Rust and React debugging

- Run `RUST_LOG=picket_app=debug,picket_core=debug RUST_BACKTRACE=1 make dev` for local diagnostics.
- Install the recommended VS Code extensions from `.vscode/extensions.json`.
- Use **Picket CLI: doctor** to set Rust breakpoints without a window.
- For desktop breakpoints, start `pnpm dev:ui`, then launch **Picket desktop (run pnpm dev:ui first)** in VS Code.
- Use the development webview inspector for React, IPC, and CSS diagnostics. Never add a production remote-debugging port.
- Close the app through its tray menu before a fresh native launch; single-instance behavior focuses an existing process.

`pnpm check:env` checks tool availability. `cargo run -p picket-cli -- doctor` prints only the app version, platform, architecture, and inactive monitoring state. Neither accesses accounts or personal files.

## Test boundaries

`make check`, `make test`, `make e2e`, and `make audit` cover the present foundation. Browser tests verify layout, keyboard interaction, browser-preview disclosure, lack of external UI requests, and console errors. `make smoke-macos` builds and launches the packaged app, checks its Rust IPC status, closes it to the tray, confirms the tray remains present, restores the existing process through a second launch, and quits it. Grant Accessibility access to the invoking terminal before running that macOS-only check. A direct tray click needs a brief manual check because macOS does not expose a real tray click through the accessibility action used by the script.

These checks do not prove future macOS permissions, notifications, direct tray clicking, or real account integration. The development app uses an ad hoc code signature so its bundle can be validated consistently. A public release still requires a Developer ID identity and notarization.

Playwright artifacts are ignored under `test-results/`; failures keep traces and screenshots. CI runs without retries so flakes remain visible. The portable core and CLI run on Linux; the full desktop workspace compiles and tests on macOS.

Introduce mock-model evaluation gates with the real replay engine and scenario baseline in M3/M4. Do not add an empty feature gate, fabricate a baseline, or report zero scenarios as a successful evaluation.

## Dependency and release policy

Only dependencies used by the foundation are installed into its manifests. Add collector, SQLite, OAuth, and AI crates in their owning milestones after API and license review. The design's `serde_yaml` choice needs a maintained implementation review before rule loading. The model's exact GGUF artifact, checksum, and license must be verified before download.

GitHub Actions have immutable commit pins; Dependabot tracks Actions, Cargo, and npm changes. Cargo-deny rejects disallowed licenses, known vulnerabilities, yanked crates, and unknown sources. Duplicate transitive versions are permitted because the native stack requires them. Unmaintained advisories are enforced for workspace crates; transitive maintenance warnings need review when choosing/upgrading native dependencies.

Release automation, attestations, DMGs, and the Homebrew tap are M9 work. The current workflow only checks and builds; it never publishes a release.
